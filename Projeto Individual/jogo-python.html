Como jogar

Pule antes que o personagem alcance um obstáculo. Quanto mais tempo sobreviver, maior será a pontuação. Ao colidir, use Jogar de novo ou pressione Enter para reiniciar.

O jogo usa Python executado no navegador pelo PyScript. É necessária uma conexão com a internet para carregar o ambiente Python.
